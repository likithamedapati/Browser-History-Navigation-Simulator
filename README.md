🌐 Browser History Navigation Simulator

A Python-based browser navigation simulator that demonstrates stack data structure using real-world back and forward browsing behavior.

This project mimics how modern browsers manage navigation history using two stacks.

🚀 Features

Visit new web pages

Back navigation (stack pop)

Forward navigation (stack push)

Refresh current page

Show browsing history

Display recent pages (user-defined)

Page visit counter

Clear history safely

Homepage navigation

Interactive menu system

🧠 Concepts Used

Stack (LIFO)

Lists in Python

Dictionary for tracking visits

Loops & conditionals

User input handling

Data tracking & simulation

▶ How to Run

Clone or download the project

Open terminal in project folder

Run:

python main.py

📂 Files

main.py → Browser simulator program

README.md → Project documentation

🎯 Purpose

This project demonstrates how stack data structures are used in real systems such as browser navigation. It helps strengthen understanding of DSA concepts through a practical simulation.
